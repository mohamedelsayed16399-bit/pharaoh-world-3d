# 🏺 عالم الفراعنة (Pharaoh World)

عالم مفتوح ثلاثي الأبعاد بيتولد وانت ماشي — بهوية مصرية. مجاني بالكامل، يعمل في المتصفح، بدون تسجيل.

## المميزات
- عالم لا نهائي بيتولد إجرائيًا: كثبان، جبال، واحات، ونهر النيل
- آثار مصرية: أهرامات، معابد، أبو الهول، مسلّات
- قرى فيها سكان بيتكلموا، وكهوف فيها كنوز وعقارب
- مخلوقات: جمال، تماسيح، جعران — ومومياوات بتطاردك بالليل
- نهار وليل وطقس متغير (صفاء / عاصفة رملية / مطر)
- بناء وهدم بأربعة أنواع حجارة
- قتال، دهب، حفظ تلقائي على الجهاز
- تحكم كمبيوتر (WASD + ماوس) ولمس كامل للموبايل

## التقنية
Three.js من CDN — بدون أي بناء أو سيرفر. HTML/CSS/JS خام.
